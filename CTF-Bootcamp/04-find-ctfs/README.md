# 📅 Where to Find & Track Live CTFs

## Primary Source
| Site | Purpose | Link |
|---|---|---|
| **CTFtime.org** | THE central calendar & ranking site for CTF competitions worldwide. Lists upcoming/ongoing/past events, team ratings, weights, and write-ups | https://ctftime.org |

### How to use CTFtime effectively
- **Events tab** → filter by upcoming events, format (Jeopardy/A-D), and on/onsite.
- **Teams tab** → see global team rankings; find/join a team or form your own for the bootcamp.
- Each event page links to the **official CTF platform**, rules, and (after it ends) community **write-ups**.
- Weight/rating shows how "prestigious"/competitive an event is — good filter for picking events matched to your skill level.

## Notable Recurring CTFs Worth Bootcamp Participants Knowing
| Event | Style | Notes |
|---|---|---|
| **DEF CON CTF Qualifier** | Advanced, Jeopardy → onsite finals | The most prestigious CTF in the world; very hard, great to watch/read write-ups from |
| **picoCTF (annual)** | Beginner | Official annual competition version, great first live event for the whole cohort |
| **SANS Holiday Hack Challenge / KringleCon** | Beginner–intermediate, story-driven | Runs every December, free, excellent group activity |
| **Google CTF** | Intermediate–advanced | High-quality challenges, free |
| **HTB business/seasonal CTFs** | All levels | Hack The Box runs periodic themed events |

## Tip for Running a Bootcamp Finale
Set a shared team registration on CTFtime for an upcoming beginner-friendly live event as the "capstone" activity, or self-host one using **CTFd** (see `02-tools/misc-general.md`).
