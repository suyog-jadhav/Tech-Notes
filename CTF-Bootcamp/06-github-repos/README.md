# ⭐ Famous / Must-Know GitHub Repositories

Star these — you'll come back to them in almost every CTF.

## Payload & Technique Libraries
| Repo | Purpose | Link |
|---|---|---|
| **PayloadsAllTheThings** | The single biggest payload/bypass reference for every vuln class | https://github.com/swisskyrepo/PayloadsAllTheThings |
| **SecLists** | The canonical wordlist collection | https://github.com/danielmiessler/SecLists |
| **HackTricks** repo (source of the wiki) | Pentest/CTF technique reference | https://github.com/carlospolop/hacktricks |
| **GTFOBins** | Unix binaries for privesc/bypass | https://github.com/GTFOBins/GTFOBins.github.io |
| **LOLBAS** | Windows "living off the land" binaries | https://github.com/LOLBAS-Project/LOLBAS |

## Notes
- `awesome-ctf` and `ctf-wiki` are the best two single starting points if a participant asks "where do I even begin exploring."
- Many top CTF teams (`perfect blue`, `redpwn`, `PBCTF`, `Project Sekai`, `Organizers of DiceCTF`) maintain public write-up repos — searching `"<team name> writeups github"` is a reliable way to find high-quality reading material.
