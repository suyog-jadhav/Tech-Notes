## How to Use Write-ups Well
1. **Attempt the challenge yourself first** (genuinely, for a reasonable time).
2. Read only enough of the write-up to get unstuck — don't skip to the flag.
3. Re-implement the solution yourself from the technique, not by copy-pasting the write-up's exact commands.
4. Write your own short note afterward — teaching yourself back is the fastest way to retain the technique.
