# 🎯 Specialized / Niche Practice Platforms

| Platform | Focus | Link |
|---|---|---|
| **CryptoHack** | Cryptography (deep, modern) | https://cryptohack.org |
| **Root Me — App-Systems section** | Binary exploitation, RE | https://www.root-me.org |
| **GeoGuessr** | OSINT/geolocation training (fun, indirectly useful skill for OSINT CTFs) | https://www.geoguessr.com |
| **Cellebrite CTF / DFIR archives** | Digital forensics deep dives | search "DFIR CTF" archives |
| **KringleCon (SANS Holiday Hack Challenge)** | Full-stack, story-driven, beginner-to-advanced, runs annually every December, stays playable after | https://holidayhackchallenge.com |
| **flaws.cloud / flaws2.cloud** | Cloud (AWS) security misconfigurations | http://flaws.cloud |
| **CloudGoat** | AWS cloud security "vulnerable by design" environments | https://github.com/RhinoSecurityLabs/cloudgoat |
| **Damn Vulnerable Web Application (DVWA)** | Self-hosted intentionally vulnerable web app for practicing basics locally | https://github.com/digininja/DVWA |
| **OWASP Juice Shop** | Modern, self-hosted intentionally vulnerable web app (very popular in training) | https://owasp.org/www-project-juice-shop |
| **WebGoat** | OWASP's classic vulnerable web app for learning | https://owasp.org/www-project-webgoat |
| **Metasploitable 2/3** | Intentionally vulnerable Linux VM for general pentesting practice | https://github.com/rapid7/metasploitable3 |
| **ImmersiveLabs** | Enterprise-focused gamified cyber training (often has free trials) | https://www.immersivelabs.com |

## Notes
- **flaws.cloud**, **CloudGoat**, and cloud-focused labs are increasingly important as CTFs add cloud/DevSecOps categories — worth introducing in an advanced bootcamp module.
- **KringleCon** is genuinely one of the best free, story-driven, beginner-friendly full CTFs available and worth doing as a group activity.
