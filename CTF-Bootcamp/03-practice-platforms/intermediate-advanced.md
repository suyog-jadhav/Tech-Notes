# 🟡🔴 Intermediate & Advanced Practice Platforms

| Platform | Focus | Notes | Link |
|---|---|---|---|
| **Hack The Box (HTB)** | Boxes (full VM pwn) + Challenges (jeopardy) | Industry-standard; free tier + VIP; used heavily for interview prep and OSCP practice | https://www.hackthebox.com |
| **Hack The Box: Sherlocks** | Blue team / DFIR (forensics, incident response) | Great for forensics-focused learners | https://www.hackthebox.com/hacker/hacking-labs/sherlocks |
| **VulnHub** | Downloadable vulnerable VMs | Free, self-hosted, huge archive of boot2root machines | https://www.vulnhub.com |
| **pwn.college** | Binary exploitation, systems security | Free, Arizona State University — excellent structured pwn/RE curriculum with a real course backbone | https://pwn.college |
| **pwnable.kr / pwnable.tw** | Binary exploitation | Classic, well-loved pwn wargame sites, progressive difficulty | http://pwnable.kr · https://pwnable.tw |
| **crackmes.one** | Reverse engineering | Huge community-submitted crackme archive with difficulty ratings | https://crackmes.one |
| **exploit.education** | Memory corruption / exploit dev | Phoenix, Nebula, Protostar VMs — classic exploit-dev learning path | https://exploit.education |
| **CTFtime-hosted event archives** | All categories | Many past CTFs stay playable after the event ends — see `04-find-ctfs/` | https://ctftime.org |
| **RingZer0** | All categories | Long-running challenge site, decent variety | https://ringzer0ctf.com |
| **W3Challs** | Web, crypto, forensics, RE, exploitation | Ranked challenge platform with active community | https://www.w3challs.com |
| **Attack-Defense (by Pentester Academy)** | Attack-defense style labs | Good exposure to A/D format before playing live | https://attackdefense.com |

## Notes
- **HTB + pwn.college** together cover most of what serious bootcamp graduates should aim for next.
- Once comfortable, start playing **live CTFtime-ranked events** with a team — real competitions teach time-pressure and collaboration that solo practice can't.
