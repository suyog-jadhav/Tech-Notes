# 🟢 Beginner-Friendly Practice Platforms

| Platform | Focus | Notes | Link |
|---|---|---|---|
| **picoCTF** | All categories | Free, made by Carnegie Mellon, huge permanent archive of past-competition challenges with hints | https://picoctf.org |
| **OverTheWire** | Linux/command-line, web, network | Wargames like *Bandit* (Linux basics), *Natas* (web), *Krypton* (crypto) — progressive difficulty | https://overthewire.org |
| **TryHackMe** | All categories, guided rooms | Free tier + subscription; great structured learning paths for total beginners | https://tryhackme.com |
| **PortSwigger Web Security Academy** | Web exploitation | 100% free, extremely thorough, written by the Burp Suite creators, includes interactive labs | https://portswigger.net/web-security |
| **Hacker101 CTF** | Web, general | Free CTF by HackerOne, ties directly into bug bounty skills | https://ctf.hacker101.com |
| **CryptoHack** | Cryptography | Gamified, excellent for learning modern crypto attacks from scratch | https://cryptohack.org |
| **XSS Game (Google)** | XSS specifically | Small, free, official Google-made XSS challenge set | https://xss-game.appspot.com |
| **CTFlearn** | All categories | Community-driven, large beginner challenge pool | https://ctflearn.com |
| **Root Me** | All categories | Huge, free challenge library across every category, good for building breadth | https://www.root-me.org |

## Suggested Beginner Order
1. OverTheWire **Bandit** (Linux fundamentals — do this first, no exceptions)
2. picoCTF (broad exposure to every category)
3. PortSwigger Web Academy (deep dive on web once comfortable)
4. CryptoHack (deep dive on crypto)
5. TryHackMe free rooms (guided, practical)
